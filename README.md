# Taxi Diary — веб-версия

## Локальный запуск
Откройте `index.html` в браузере. Для полноценной установки PWA и корректной работы manifest нужен HTTPS-хостинг.

## Бесплатное размещение
1. Создайте аккаунт GitHub и новый публичный репозиторий.
2. Загрузите в корень репозитория все файлы этой папки.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`, нажмите Save.
5. После публикации откройте выданный адрес на iPhone в Safari → «Поделиться» → «На экран Домой».

## Важно
Данные сохраняются в localStorage текущего браузера. Они не синхронизируются автоматически между iPhone и Windows и могут потеряться при очистке данных Safari. Регулярно скачивайте JSON-резервную копию.
